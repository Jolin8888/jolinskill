# catalog制作

把产品、材质、工艺与 OEM 选择组织成可供采购客户比较和询价的图册。复用已经确认的风格和约束，交付完整 PDF、可继续编辑的工程和来源记录。

## 先确定本轮范围

- 同一图册继续修改：读取最新完整版本、产品清单、风格锁定记录和本轮修改对象；沿用已确认内容，不重新做全册设计。
- 新系列：依据现有品牌和用户参考提出一套具体版式；用户要求先看样张时，先交指定页数，确认后再扩展。已明确授权制作时继续执行，不为常规可逆步骤追加审批。
- 用户的最新明确要求优先。例如“只换三个场景”只改那三个；“新娘坐床上、丈夫单膝下跪”不更换其他章节；“合成完整的”交一份包含最新修改的完整文件。
- 不把案例的页数、场景数量、100 套 MOQ 或 FY 品牌默认变成所有项目的要求。MOQ、材料成分、认证、交期和可制造性从本项目已确认信息读取。

如果本轮是“把流程固化/更新成技能”，先进入当前可用的 skill-creator 流程，停止扩展业务图册。遵守 canonical 安装与同名目录规则，只提炼验证过的方法；检查引用、脚本、包内项目数据，并用局部替图、异形源图、B 端包装三个情境做前向评估。

- 开始新册、分类、参考调研与素材组织：读 [制作流程](references/workflow.md)。
- 选择高端/节日风格、页面比例、字体及网格：读 [风格与版式](references/style-system.md)，参数见 [样式配置](assets/style-tokens.json)。
- 图片查找、白底抠图、材质和场景、品牌文字：读 [素材规则](references/asset-rules.md)。
- OEM 包装章节：读 [B 端包装选型](references/oem-menu.md)。
- 修改 PDF、合并版本、检查与最终交付：读 [输出与验收](references/production.md)。

## 固定要求

1. **产品完整展示。** 原比例 contain 放入版面；不能裁掉边缘、拉伸、挤压、变色或为凑网格改变产品结构。画布留白可以保留。源照片本来有截边/遮挡时，不声称已恢复；保留记录并明确处理位置。
2. **产品事实与气氛概念分开。** 真实产品图优先保留原像素；新场景与包装效果图可以生成，但不能把概念描述成已生产样品、已认证产品或确定可供货的规格。
3. **一项一图，清楚分类。** 同页同类产品统一画框、视觉尺度和对齐基线，方向优先选源图一致；不为方向一致镜像文字或重绘真实商品。OEM 每种袋型、盒型、卡纸或辅料单独列项，配用途与定制说明。
4. **品牌来自用户。** 使用提供的 Logo，正式页面不保留竞品品牌/网址。排版里的 Logo 和文字尽量保留矢量。FY 主题可用本技能附带原标；其他品牌必须换为自己的原标。
5. **材质图有信息作用。** 只在材质/工艺介绍处使用有辨识度的原料、纤维、织造或整理照片；不在每页重复一张棉花图，不用错原料暗示成分。
6. **简约来自结构。** 干净页底、明确层级、留白和克制装饰；节日色彩主要来自产品与已确认的场景。不得机械地把所有页面做成深色或堆同一种场景。
7. **只改指定范围。** 保存上版，记录允许变化的页或图片。局部更换后核对其他页、原产品编号、链接和字体没有意外变化；合并交付时不能把旧页和新版重复保留。

## 工具选择

- 浏览与页面操作遵守当前环境要求；Jolin 环境默认 EgoLite，不可用时先说明再换工具。研究优先已配置的发现工具与原品牌来源，保留来源表。
- 栅格新图与编辑优先当前可用的内置图像工具；若有 imagegen 技能，读取对应使用规则。用户指定传统抠图时按该要求保留原 RGB，不用生成式工具替代。
- PDF 用可重现的排版脚本和正式渲染器；可用时遵守当前 PDF 技能的要求。优先现有文档运行环境，不把某台机器的临时路径写进项目脚本。
- 排版可调用 [contain helper](scripts/layout_helpers.py)。结构检查运行 [catalog_qc.py](scripts/catalog_qc.py)，参数和 manifest 见 [使用说明](scripts/USAGE.md)。结构 PASS 不能替代视觉检查。传统抠图可用 [verify_cutout.py](scripts/verify_cutout.py) 验证商品保护区域；遮罩与边缘仍须人工核对。

## 交付约定

交付一份明确标记为当前版本的完整 PDF；修改很多时另附精简修改页预览。用户只要完整册时，不让多个零散文件成为唯一交付。保留可编辑工程、原始图片、生成提示词、来源与检查记录。正文只说明完成内容、文件和实际限制。

此技能不自行授权公开发布、付费生成、上传客户素材或同步外部项目库。遵守用户本次授权、目标仓库与此前同步选择；公开分享技能时只分享可复用规则和获准资产。
