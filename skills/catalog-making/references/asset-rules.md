# 素材规则

## 完整与真实性

- 用完整源画布进行等比 contain，不用 cover、overflow hidden、固定宽高拉伸、自动填满边框。对产品允许透明背景和阴影，不为去白边裁到产品轮廓。
- 独立保存母图。允许为交付重新编码；原像素精确保留必须以解码 RGB/alpha 校验为证据，不能仅凭肉眼或文件尺寸宣称。
- 传统抠图只改 alpha/背景，不重绘颜色、纹理、轮廓或接缝。用户明确要求保留原像素时，生成式背景编辑不能替代。
- 源图本来缺边、被家具遮挡或像素不足：记录问题，寻找同款完整源图，或按用户决定保留在参考页。不要把 AI 补全当成原款真实部分，不静默删款。
- 同页的朝向与透视先通过选图统一。完整商品的尺寸/朝向不能为了视觉整齐硬改；通过画框、中心线、基线和留白取得一致性。

### 传统抠图的可验证步骤

保存未缩放母图、同尺寸透明 PNG 和经人工检查的商品保护蒙版。蒙版覆盖应保留的完全不透明商品内部，不把要删除的背景或半透明抗锯齿边缘算作内部。使用 [verify_cutout.py](../scripts/verify_cutout.py) 比较保护区域的 RGB 与原图完全一致、alpha 保持255；抠图其他区域可以透明或改变背景。随后单独放大检查轮廓、细带、绒毛和接缝，没有被蒙版漏选或误删。蒙版本身是否覆盖正确不能由这一比较自动证明。

完整 RGB 不变只改 alpha 的工作流可以将全部商品内部纳入同一保护。已合成白底或重新编码 JPEG 的交付副本不用作原像素证明；验证针对未缩放无损母版。

## 原料与工艺

原料特写要能解释对应材质；棉花不代表亚麻，麻杆/亚麻纤维不代表棉，蚕茧/丝束不代表羊绒。品牌纤维或地域名称必须有来源，不从纹理猜认证和成分。

为重要材料开篇选择大而清楚的原料图，配成品/织物细节形成关系。每种材料缺少原料图时，可用真实相关的纺纱、织造、刺绣、提花、后整理过程。不要每个产品下重复同一棉花照片，也不要把原料缩成无意义小贴纸。

## 参考研究与自有场景

Pinterest 可作发现入口，尽可能追到品牌/摄影原页保存来源。参考画册提取层级、配色、留白和拍摄关系；正式图片优先使用用户自有素材、适用授权素材或独立生成概念。保留第三方参考和生成成品的区别。

新场景用真实自然的采光、织物重力与材质，构图预留标题和 Logo 空间。姿态有具体要求时写成可验证动作：如“新娘坐在床的床沿，丈夫一膝触地另一脚踩地”，检查坐在床还是凳子、单膝还是双膝、手脚是否自然。不要只写抽象的“浪漫高端”。

新图生成与编辑跟随当前图像工具使用规范。图片型任务用图像工具；可编辑文字、Logo、页码和链接由排版层叠加。一次生成一项独立资产，避免将多个类别拼成无法拆用的大图。

## 品牌与链接

- 正文采购链接只用项目已确认的官网、邮箱等；不把竞品商店网址冒充客户询价入口。
- 参考图上其他品牌/水印不进入最终自家产品宣称。用新概念图表达可定制包装；仅在用户有权修改的素材上做指定品牌替换，并标注必要的概念属性。
- Logo 用原 SVG/矢量，文字精确核对大小写。深色底上必须可读，包装的小标签也要按最终页尺度检查。
- 字体子集不一定含新文字映射。追加文字使用完整授权字体或重新生成矢量排版，检查是否出现方框/缺字。

## 生成提示词结构

Use case；用途；主对象/单品类型；参考图角色；材料与配色；摄影角度；完整边缘与留白；需要逐字出现的品牌；不可改变的部分；避免项。

单品示例要点：一件指定盒型 / 完整包含所有边缘 / 统一白或浅米背景 / 温和真实阴影 / 精细纸纹与绸带 / 品牌逐字为用户要求 / 不出现其他品牌 / 不混入其他包装品类。

内部记录每张最终素材的本地路径、原始来源、生成或编辑方法、提示词、原始尺寸和审核结果。公开技能包不带客户产品库、私人联系资料或第三方研究图片。
