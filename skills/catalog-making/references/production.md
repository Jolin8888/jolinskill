# 输出、修改与验收

## 可重复的工程

建议在当前项目内保存：brief/已确认约束、产品台账、来源表、原图与派生图、品牌文件、排版源码、输出 PDF、提示词和 QA 记录。只在 canonical skill 目录维护技能；其他项目引用技能，不复制第二份实体技能。

业务数据留在项目，通用脚本留在技能。运行时使用已配置的文档 Python/Node 环境；本技能脚本需要 PyMuPDF，排版可用 ReportLab；按环境可用性选择。缺少依赖先说明，不静默改用外部 API 或付费服务。

图片完整放入：`scale=min(frame_w/source_w, frame_h/source_h)`，宽高乘同一比例并居中，使用 [layout_helpers.py](../scripts/layout_helpers.py)。透明 PNG 保留 alpha，产品 RGB 不作无关变换。可为 PDF 生成交付 JPEG，但保留母图；不要将 JPEG 编码等同于原像素精确无损。

文字、Logo、页码和链接优先做可编辑矢量层。PDF 字体须能在交付端显示。字体子集复用到新字串可能出现空方框；追加文本用完整字体或重新排版并渲染确认。金属印刷效果是视觉示意，不暗示 PDF 能保证实体印刷质感。

## 局部修改

1. 保存上一份完整 PDF，并列出允许改变的页/资产。
2. 固定原字版、Logo、图框与页面比例；只替换本轮指定对象。图像编辑先检查原图并明确不变量。
3. 若只换一个独立栅格图，可替换其 PDF image XObject；先确认该 xref 没有在其他页共享，否则复制资源或重新生成该页。不能误改所有引用同一图的页面。
4. 图尺寸比例一致才直接替换；比例不同先重新规划 contain 留白，不裁剪新图配旧框。旧图需要腾出版面时，改对应页而不是把字体硬挤到人物脸上。
5. 验证目标资产确实替换：保存替换前后图像记录，baseline 使用 `--required-changed-pages` 加 `--allowed-changed-pages`。允许变化不等于已经变化。页级变化也不证明语义正确：逐项确认人物动作及目标页内的标题/Logo等非目标元素。
6. 检查新姿态、图像边缘、标题安全区、Logo 对比及实际阅读尺度，然后比较其他页。正常只改单页时，其余页渲染应一致。

## 合并完整册

明确主册基准和哪些附录需要并入。防止重复旧页、漏掉新场景、静默删产品或把旧的修改预览再次拼到完整册尾部。

默认保持已确认的封面和封底位置；参考附录可放联系页之前。更新目录、书签、页码、内部跳转和总页数。存在原始截边/遮挡的参考图应保留适当参考说明，不谎称白底完整实拍。

插页后不能按同页号盲比，保存 old→new 页码映射。用同一渲染器比较对应页面，不仅对比 PDF 文件字节（压缩和对象编号会改变）。

## 自动检查 + 视觉复核

使用 [catalog_qc.py](../scripts/catalog_qc.py)，manifest 与 CLI 见 [USAGE](../scripts/USAGE.md)。至少提供预期页数、完整产品/OEM 编号及已确认链接列表；结构检查输出 JSON，避免在对话里堆日志。

检查分工：

| 检查 | 能证明什么 | 仍需补充 |
|---|---|---|
| 编号清单各出现一次 | 已声明文本编号未丢失或重复 | 图片中的编号、每图是否真对应产品 |
| 图像变换与 MediaBox | 等比、无剪切且位置在页内 | PDF clip/mask、原图预裁剪、商品边缘 |
| 链接 allowlist | 仅允许的完整网址/邮箱 | 网络可达性、邮箱实际投递能力 |
| 字体资源 | 嵌入情况及可能问题 | 未使用默认资源不是实际缺字；逐页看文字 |
| baseline 渲染比较 | 同尺寸/同页号的可见改动范围 | 插页要映射；小尺寸可能漏细微变动 |
| RGB/alpha 对照 | 源与派生商品像素有无改变 | AI 场景不等于真实产品实拍 |

最终必须渲染。全册看联系表，再放大查看封面、目录、每个新/修改页、长文案、Logo、品牌文字、联系页和封底；有问题修正后只重复受影响检查及必要完整性检查。

需要核对：无方框缺字、文字相撞、裁边、拉伸、漂白变色；同类画框/间距/尺度一致；材料与工艺照片不误导；原料图不机械重复；标题与人物/产品不冲突；所有包装品牌精确拼写；目录和页码有效。

结构 PASS 不是最终视觉批准。若保留问题，报告实际限制，不写“全部无问题”。原图不可恢复时保持可追溯，不无限生成假实拍。

## 交付与复用

交付当前完整 PDF，按需附修改页预览、单张图片或素材包。简短说明变化、验证和剩余问题。链接使用实际可访问的交付路径；PDF 引用格式遵守当前宿主工具要求。

保存可继续工作的状态：目标、当前版本、已确认决定、输入输出路径、已完成检查、问题和下一步。若用户将制作流程提升为技能，只提升已验证通用规则；MOQ、产品数、私人邮箱与本机绝对路径不进入公共能力模板。
