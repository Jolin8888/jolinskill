# 风格与版式

## 共用视觉语言

目标是高端、克制、清晰的编辑式产品目录。大标题与小而整齐的导航形成层级；产品图呼吸充分，页内元素靠网格对齐。避免满页装饰、繁复解释和为了填空而重复素材。

FY 历史样式采用细衬线标题与自然斜体、副文案使用清楚的小字号无衬线。已用字体为 Didot 常规/斜体、Baskerville、Arial。若字体不可用或没有使用授权，先选本环境可用的授权替代；没有用户字体文件时不要宣称“完全是原字体”。不要把商业字体文件打包上传公共仓库。

## 两个样式方向

### Premium / 高端定制

- 低饱和深棕、暖白/米白、克制的香槟金点缀。
- 深色封面文字用米白或白色；香槟金的光泽来自自然高光、纸张/印刷材质或经确认的效果，不用泛黄平涂冒充金属。
- 原参考的底纹是低对比、印在纸面上的纹理；不要擅自改成凸起的大浮雕字母。
- 大面积材质特写与精简材料说明可以成为视觉主角。黑底不是高端的必要条件。

### Festival / 节日系列

- 产品页以统一白底为主，色彩来自织物、图案、包装与节日主题。
- 编辑式大场景只用于封面/章节引导等已确定位置。产品列表以完整单品或明确的细节图为主。
- 自然人物互动、柔和采光、适当节日线索与留白。万圣节应能从南瓜灯/服装/装饰看出来；Wedding 从婚纱/头纱/婚礼动作看出来；Back to College 从宿舍尺度/搬入物件/学习环境看出来。不要只改标题却没有主题识别。
- 节日感可以鲜明，但不默认把首页粉、尾页绿等大块底色混用。保持同册稳定。

## 已验证的横版基线（可调整）

当源场景为 3:2 且用户未锁定其他页幅时，900×600 pt 横版可整图放入，无需裁剪。其他比例应先依据内容规划页幅，不强制所有图变成 3:2。

| 元素 | 横版基线 |
|---|---|
| 页面 | 900×600 pt |
| 顶部导航 | x=32 / 326 / 868；页码右对齐；y≈24 |
| 正文边距 | 左右 40–42 pt，最低不压到页边 |
| 产品图 | 三列 250×250 pt；x=40 / 325 / 610；统一顶部约157 |
| 两列/单列 | 保留同一图框尺度，整组居中；勿把单件无限放大 |
| 产品页标题 | 约29–30 pt，细衬线；y≈76–80 |
| 产品名 | 约11–12 pt；信息层级需真实尺寸渲染检查 |
| 产品说明 | 约9–10 pt；历史密集页8.3 pt可用，需检查阅读尺度 |
| 页脚导航 | 约6.5–7.5 pt；不能承担关键信息 |
| 场景大标题 | 约37–66 pt，依据留白和长短调整 |
| 斜体引导语 | 约17–22 pt，不挤压主要标题 |

长名称换行或调整版面，不通过横向压缩文字/图片解决。不同长宽比照片使用同框 contain，允许出现留白；产品本身有不同尺寸时，不虚构实际比例关系。
