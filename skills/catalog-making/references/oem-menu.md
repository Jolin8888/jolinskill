# B 端包装选型

采购客户需要看见不同选择及可讨论的规格。每项有自己的完整图片、编号、名称、结构/材料说明、适用产品和定制项。不要把礼盒、袋子、吊牌、织标都摆在一张图里代替选型清单。

下表是可复用的概念菜单，不是自动承诺已经具备的生产能力。按本项目供应与确认情况选择；效果图标注为概念，具体尺寸、材料、工艺与 MOQ 以项目确认样/报价为准。

| 类别 | 选项 | 展示与描述重点 | 可讨论的定制项 |
|---|---|---|---|
| 礼盒 | 天地盖礼盒 | 盒盖与盒底作为同一结构；可示意折叠床品 | 尺寸、纸纹、烫金、绸带 |
| 礼盒 | 抽屉盒 | 单个套筒与滑动托盘；小礼品用途 | 盒深、内衬、拉片、表面工艺 |
| 礼盒 | 磁吸折叠盒 | 同一个盒的开盖状态 | 折叠结构、内衬、印刷、尺寸 |
| 袋型 | 束口布袋 | 完整袋形、绳/带结、细微标识 | 面料克重、尺寸、抽绳、标识 |
| 袋型 | 纸袋 | 独立袋型和封口方式 | 纸张、底/侧褶、印刷、封口贴 |
| 袋型 | 拉链收纳袋 | 提手、拉链、透明窗与容量关系 | 尺寸、视窗、拉链、面料、标签 |
| 包裹 | 可复用布包裹 | 结饰、织物肌理和整体体积 | 布幅、织法、颜色、缝标 |
| 包裹 | 节日包装纸 | 格纹/图案与配套色 | 印花循环、纸重、绸带、吊牌 |
| 包裹 | 品牌薄纸 | 独立内层包装和封口贴 | 纸重、Logo重复、颜色、封口 |
| 卡纸 | 双面吊牌 | 形状、边框、穿孔；正反信息可分开说明 | 形状、印刷、烫金、孔与挂绳 |
| 卡纸 | 压纹祝福卡 | 纸张厚度和压纹光影 | 压纹、纸张、节日语、烫金 |
| 卡纸 | 留言卡与信封 | 同一套卡片与配套信封 | 卡幅、信封、边框、文案 |
| 品牌/封口 | 腰封 | 宽度和折叠包裹方式，可用一件织物作尺度参考 | 纸张、折线、信息区、印刷 |
| 品牌/封口 | 定制织带 | 单个带卷与自然尾端，边缘完整 | 宽、色、长度、织/印标 |
| 品牌/封口 | 封口贴 | 贴纸或整张标签纸 | 形状、大小、胶、表面工艺 |
| 纺织辅料 | 对折织标 | 真实织纹、折法和品牌字样 | 尺寸、纱色、折法、图案 |
| 纺织辅料 | 洗护成分标 | 品牌、信息区和洗护符号 | 语言、真实成分、符号、规格 |
| 纺织辅料 | 滚边细节 | 一块完整边角样片，颜色和走线清晰 | 包芯大小、布料、色、缝制位置 |

图片规则：每张只表达一个可选结构，必要的盒盖/盒底或卡/信封属于同一选项，不算乱拼。纸张、布料、织带和压纹分别体现真实触感。统一白/浅米背景、完整轮廓和大致一致的观看角度；带人物的陈列场景不替代 OEM 单品图。

常用三列版式：250×250 pt 图片；下方为编号、名称、结构一句话、USE 与 CUSTOM 两个短字段。每页一个类别，说明为英文或项目要求的语言。没有确认的工厂能力使用“可讨论/待打样”的语义，不虚构认证、交期、免费服务或全部品类统一 MOQ。

如用户要求保留已有独立包装照片，优先从原始素材取图，不从参考拼板截图裁出低清图片。品牌拼写需逐张验收，不能只检查页面标题。
