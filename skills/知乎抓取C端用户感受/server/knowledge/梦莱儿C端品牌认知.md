# 梦莱儿 C 端品牌认知

> 内部使用。来源：Jolin 于 2026-08-25 提供的《梦莱儿品牌手册》及品牌人格系统。每日消费者洞察、产品建议和内容导航必须先遵守本文件，再结合当天及历史证据分析。

## 一、已确认的业务与渠道

- 梦莱儿是大润发线下商超渠道的床上用品品牌。
- 梦莱儿同时经营天猫店铺和小红书店铺，并通过微信贴图、公众号等私域内容触达消费者。
- 适用触点：天猫店铺、小红书、大润发终端、包装吊牌、微信贴图、公众号、客服与售后话术。

## 二、品牌定位与人格

### 品牌人格核心

**懂她疲惫的那个人。**

不是导师，不是推销员，不是激励号召者，而是一个真实存在、不评判，在她放下所有角色之后还记得她是谁的人。

核心品牌句：

> 你把最好的给了这个家，梦莱儿把好的还给你。

品牌信条：梦莱儿，为懂得珍惜自己的她。

品牌 Slogan：回归本我睡眠状态。

### 人格四维

1. **温柔：有温度，不煽情。**语气像牵手，不是推背；承认辛苦，不用眼泪换转化。
2. **有力：给许可，不给压力。**告诉她“本来的样子就够了”；内核稳定，不随焦虑起伏。
3. **真实：不滤镜，不造神。**不卖精英叙事，不造完美家庭；普通的早晨和普通的床也值得被好好对待。
4. **平视：朋友，不是品牌。**说人话，不说品牌话；她懂的不重复说，她需要听的才开口。

### 情感主张

- **看见付出：**她一直在给予，梦莱儿反过来看见她；不是同情，是尊重。
- **不用证明：**她不需要先成为好妈妈、好妻子或好员工，才值得好好睡。
- **买得起的好：**平价不是退而求其次，而是聪明、主动的自我善待。
- **睡眠是修复：**睡眠不是停机。身体被承托、温度恰好、肌肤被柔软包裹、心绪安静下来，才是真的睡好。

## 三、产品力表达模型

梦莱儿的产品力以“触、温、托、静”四个睡眠感触支柱组织：

| 支柱 | 消费者收益 | 主要品类 | 内容表达方向 |
|---|---|---|---|
| 触 | 肌肤接触柔软、舒服、少刺激 | 四件套 | 把面料成分、织法、触感、洗后表现翻译成“贴到皮肤是什么感觉” |
| 温 | 不忽冷忽热，适配季节和睡眠体感 | 被芯 | 把填充、克重、透气、贴合、适用温度翻译成“什么天气、什么人盖着合适” |
| 托 | 高度、软硬和回弹适配睡姿，颈肩得到承托 | 枕芯 | 把受压后高度、软硬、回弹、分区翻译成“仰睡、侧睡分别怎么选” |
| 静 | 触感、温度和环境共同减少睡前干扰 | 四件套及整体睡眠场景 | 以真实普通的卧室、晨光或夜间暖光表现松弛和安静 |

产品卖点一律使用以下公式：

> 用户问题或使用场景 + 消费者收益 + 产品机理／参数证据 + 适用边界

消费者需求不能直接写成梦莱儿已有功能。没有真实 SKU、材料、检测或使用数据支撑时，必须标注“需产品资料验证”。“恒温、精准承托、抗菌防螨、亲肤”等词只有在存在相应参数、检测或结构证据时才可作为产品事实。

## 四、语言风格

### 应该这样说

- 短句，停顿有力；用具体的触感、气味、温度和动作。
- 说“你”，不说“女性”；说“睡好了”，不说“品质睡眠”。
- 承认普通，接纳不完美；功能也要翻译成人话。
- 情绪点到即止，结尾留白，不催行动。
- 示例：“今天也辛苦了，先把自己放下来。”“贴着皮肤那一下，让人松一口气。”“希望你睡好。”

### 不应该这样说

- 不用年龄焦虑、完美主妇、精致妈妈、身材或颜值暗示切入。
- 不说“赋能、悦己、内卷、品质之选”等空话。
- 不用“别人都在用”、限时、库存紧张、全网最低等压力转化。
- 不说教，不命令，不居高临下；不使用冷冰冰的参数堆砌。
- 禁用违反广告法或不符合品牌气质的绝对化词语，如“最、第一、顶级、最佳、永久”。

## 五、渠道与内容职责

### 大润发线下终端

- 负责真实触摸、家庭场景询问、低风险试选和即时成交。
- 陈列语言为“一句场景句 + 一个价格”，不堆卖点。
- 货架牌说“你今晚”，不说“本品特点”。导购先问家庭和睡眠情况，再推荐 SKU，不做价格攻势。

### 天猫店铺

- 负责搜索承接、参数比较、证据解释、规格选择和成交。
- 主图用场景句，不堆功能；首屏说清“这是谁的床”。
- 详情页节奏：情绪共鸣 → 真实触感 → 材料事实 → 价值确认。客服先问需求，不催单。

### 小红书

- 负责场景种草、真实体验和选择教育。
- 每条内容只做一件事：要么共鸣，要么种草，不同时完成两个目标。
- 文案从一个真实问题或生活片段进入，再提供选择方法或使用体感；不伪造用户体验。
- 视觉使用低饱和宋式青绿体系、自然晨光或夜晚暖光、真实不完美的生活感。

### 微信贴图

- 负责在私域中快速传达一个卖点或一个被看见的瞬间。
- 一张图只保留一个主标题、一个具体副标题和必要的产品证据；不能做参数墙。

### 公众号

- 负责完整解释、材质和结构对比、选择指南、长期信任与品牌价值沉淀。
- 一篇文章解决一个明确问题；结构可用：真实场景 → 为什么难选 → 简单选择方法 → 梦莱儿可验证的产品事实 → 适用与不适用边界 → 松弛收尾。

### 包装、客服与售后

- 吊牌背面放一句品牌句，不用二维码强行引流；包装克制，内容物比仪式感更重要。
- 投诉先承认感受，再解决问题。结尾不说“感谢您选择梦莱儿”，说“希望你睡好”。

## 六、视觉基线

- 主色：宋青绿 `#7E988A`；辅色天青 `#A9C2B6`、月白 `#E8EDE7`、梅子 `#5A2B3F`、燕麦米白 `#E9E0CF`、雾棕 `#B09F8D`、暖金 `#E3C797`、酒红玫瑰 `#8B395D`。
- 用色比例：基底 70%、主色 20%、点缀 10%。整体低饱和、暖中性、留白充足。
- 摄影至少使用三项代码：慵懒体态、材质肌理、晨柔光或夜暖光、情绪留白、近距细节、真实不完美。
- 禁止冷白直射光、网红脸、过度磨皮、僵直站姿和过度完美的家庭幻觉。

## 七、每日输出的两个用途

### 用途一：品牌定位优化

每日结合新旧消费者证据检验“懂她疲惫的那个人”是否清晰、可信且能由产品证明。允许提出定位候选或微调，但必须写清：目标人群与购买任务、核心价值、与常见表达的区隔、三渠道如何证明、成立所需的产品和经营证据。未经验证只能写“建议定位”或“待验证定位”。

### 用途二：分品类日常内容卖点

每日按枕芯、被芯、四件套分别提供 2—3 条优先卖点，再转写成：

- 小红书：标题／开头、正文切入和图片场景。
- 微信贴图：一个主标题、一个副标题、一个产品证据。
- 公众号：选题标题、核心观点和内容提纲。

三端不能复制同一句文案，且每条卖点都要回到“触、温、托、静”之一，并注明需要梦莱儿提供什么产品资料才能成立。

## 八、发布前一致性检验

每次发布内容或设计物料前必须回答：

1. 这条内容在贩卖焦虑，还是在释放焦虑？
2. 我是在看见她，还是在要求她？
3. 如果她今天很累，这条内容会让她更累，还是让她喘口气？

任何一问未通过，内容不得发布。

## 九、当前证据缺口

- 当前主力 SKU、成交价格带、销量、毛利、库存和退货率。
- 各品类具体面料、填充、克重、结构、工艺、洗后表现和检测认证。
- 天猫、小红书的流量、搜索词、收藏、加购、成交和内容表现。
- 大润发门店分布、陈列资源、重点档期、导购反馈和消费者现场问题。

上述信息未补齐前，每日报告可以提出建议和验证方案，但不得声称梦莱儿已经具备对应产品力。
